# Rule Management & Context Updating Standard

1. **Rule Review Prompt Requirement**:
   - Whenever a significant feature, architectural shift, schema modification, or new technology integration is implemented, the agent MUST explicitly ask the USER if they wish to add a new rule or update an existing rule file inside `AGENTS.md` or `.agents/rules/`.
   - This ensures project conventions and architectural decisions are continuously preserved and up to date.
